# Advanced Dashboard

A responsive administration dashboard interface built with vanilla web technologies.

## Project Concept

The project focuses on a clean dashboard experience for monitoring business information through cards, navigation, customer sections, recent activity, and a responsive sidebar.

## Highlights

- Responsive dashboard layout
- Sidebar navigation
- Summary and analytics cards
- Customer and activity sections
- Mobile menu interactions
- Light/dark theme interaction
- Material Icons and custom styling

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Material Icons
- Poppins font

## Run Locally

```bash
git clone https://github.com/AbdUlkaderAlmalky/advanced-dashboard.git
cd advanced-dashboard
```

Open:

```text
dashboard/index.html
```

## Purpose

A frontend practice project for building structured, information-dense interfaces that remain usable across different screen sizes.
